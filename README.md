# The Great Bypass: IETC 2026

Interactive HTML deck for Micah J. Miner's IETC 2026 breakout, "The Great Bypass: Pedagogical Friction as Response to Tertiary Algorithmicity in the Age of Algorithms & AI." Thursday, November 12, 2026, 12:05 to 12:55 PM, DoubleTree Salon C, Springfield.

Built from `future-ready-not-just-ai-ready` (the October 6 keynote): same engine, styles, interactions and clips, with the vendor and Portrait sections removed and the research names, learning science, and study status added for the IETC description.
